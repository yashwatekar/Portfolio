# Yash Watekar — Portfolio

My personal portfolio website, built as a single-page static site.

**Live site:** https://<your-username>.github.io/<repo-name>/ *(update after enabling GitHub Pages)*

## About

This site showcases my projects, skills, certifications, and contact details. It's a single self-contained HTML file — no build step, no dependencies to install.

## Tech Stack

- HTML5, CSS3 (custom properties / CSS variables), vanilla JavaScript
- [Google Fonts](https://fonts.google.com/) — Space Grotesk, Inter, JetBrains Mono
- No frameworks, no build tools

## Features

- Responsive layout with mobile navigation
- Animated cursor trail (disabled automatically for reduced-motion / touch devices)
- Project explorer with tabbed panels
- Expandable certification cards
- Copy-to-clipboard contact tiles
- Scroll-triggered reveal animations

## Running Locally

No build process needed. Clone the repo and open `index.html` directly in a browser:

```bash
git clone https://github.com/<your-username>/<repo-name>.git
cd <repo-name>
open index.html   # or just double-click the file
```

## Deployment

Hosted via [GitHub Pages](https://pages.github.com/):

1. Go to **Settings → Pages**
2. Set source to the `main` branch, `/ (root)` folder
3. Save — the site will be live at `https://<your-username>.github.io/<repo-name>/`
